# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-07-24
### Added
- Initial release of EvalBench AI
- FastAPI backend with prompt versioning, dataset management, and evaluation runs
- LLM-as-judge and hallucination detection modules
- RAG metrics evaluation
- A/B testing support for prompts
- Streamlit dashboard for analytics and visualization
- Local-only evaluation pipeline using Ollama models
