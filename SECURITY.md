# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | Yes       |

## Reporting a Vulnerability

If you discover a security vulnerability, please do not open a public issue.
Report it privately via GitHub's private vulnerability reporting feature or
by contacting the repository owner directly.

Include a description, steps to reproduce, and potential impact.

## Notes

EvalBench AI runs entirely locally with no cloud calls by default. Don't
expose the API or dashboard ports on a public network without adding
authentication.
